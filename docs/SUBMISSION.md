KredoFi: prove your income on NEAR without showing your bank statements, and borrow USDC against it with no collateral.

Today an unsecured loan means handing over every statement. With KredoFi, a borrower connects a bank through Plaid and a pinned scorer runs inside an Intel TDX enclave through OutLayer. It uses the last six full months, applies five public rules (income level, steady income, on-time payments, money left over, savings buffer) and returns eight fields to the contract's private callback. The band, score, coarse income bucket and keyed bank fingerprint are public on-chain, as are loans. Statements, balances, exact income and the borrower's name are not (the name is sealed for a recovery partner, opened only after a default). The contract accepts a score only from its own request to the scorer build it pins by SHA-256, and a new build waits behind a 24-hour public time lock on mainnet.

The first use is small USDC loans from a lender pool: up to $100 at first, set by band and income, rising after qualifying repayments. A reserve pays losses first, and anyone can mark a default after the grace period. A second contract (partner vault, on testnet) reads the band to set its collateral terms, so other NEAR apps can reuse the score.

Everything is checkable: the scorer builds reproducibly on x86_64 Linux, the published WASM hashes to the pinned version, and each enclave run has an Intel TDX attestation. In-app, "Verify my score" runs OutLayer's open-source verifier on your own score: PROVEN only when every check passes.

Real vs test: the live demo (https://kredofi.xyz) is on NEAR testnet, scored in OutLayer's testnet enclave, with Plaid's sandbox bank and test USDC, no wallet needed. Mainnet kredofi.near runs the same scorer's production build in OutLayer with a PROVEN attestation, but on sandbox data, with lender deposits locked until real bank data and no loans made. The developer holds the sealing and Plaid keys; the site lists every such limit.
